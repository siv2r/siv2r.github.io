Fri Jul 03 2026

Chapter 3 swaps the language of events-as-sets for random variables, which are functions that turn outcomes into numbers. Once outcomes are numbers you can do arithmetic on them, and a distribution is the object that records how probability is spread across those numbers.

Why Numbers Beat Sets

Up to Chapter 2 an event is a set of outcomes, and the only tools are set operations: union, intersection, complement. That is limiting. You can intersect "it rains" with "I carry an umbrella", but you cannot add two events, or XOR them, or double one. There is no arithmetic on sets of outcomes.

A random variable fixes this by mapping each outcome to a number:

X:Ω→R.X : \Omega \to \mathbb{R}.X:Ω→R.

Now the outcomes are numbers, so X+YX + YX+Y, 2X2X2X, and X⊕YX \oplus YX⊕Y all mean something, and each is itself a new random variable. That is the real reason random variables exist: they let you build new quantities out of old ones.

A random variable adds no randomness of its own. The randomness lives in the underlying experiment, the sample space Ω\OmegaΩ. The variable relabels those outcomes as numbers, and in doing so it induces a new distribution on the numbers. Same randomness, new bookkeeping.

The simplest kind is an indicator random variable, which is 1 when some event happens and 0 otherwise. It answers a yes/no question as a number, and adding up indicators is how you count events.

The PMF: a Random Variable's Fingerprint

A discrete random variable, one whose range is finite or countable, is fully described by its probability mass function:

pX(x)=P(X=x).p_X(x) = P(X = x).pX​(x)=P(X=x).

Read P(X=x)P(X = x)P(X=x) as the probability of the event {ω:X(ω)=x}\{\omega : X(\omega) = x\}{ω:X(ω)=x}, all the outcomes the variable sends to xxx. The PMF lists, for each value the variable can take, how much probability lands there.

Two conditions make a function a valid PMF. It is nonnegative, pX(x)≥0p_X(x) \ge 0pX​(x)≥0 for every xxx, since probabilities cannot go below zero. And it sums to 1 over the support, ∑xpX(x)=1\sum_x p_X(x) = 1∑x​pX​(x)=1, since the variable takes some value with certainty.

The PMF is what people mean by "the distribution of a discrete random variable". Hand me the PMF and I know everything probabilistic about XXX.

The Named Distributions

Four distributions do most of the work in this chapter. Two are worth knowing cold.

Bernoulli: one trial

X∼Bern(p)X \sim \text{Bern}(p)X∼Bern(p) is a single trial with two outcomes, success and failure. It is the indicator of success:

P(X=1)=p,P(X=0)=1−p.P(X = 1) = p, \qquad P(X = 0) = 1 - p.P(X=1)=p,P(X=0)=1−p.

The failure probability 1−p1 - p1−p turns up so often it gets its own letter, q=1−pq = 1 - pq=1−p. That is the whole distribution. Every yes/no experiment with success chance ppp is a Bernoulli.

Binomial: n independent trials

X∼Bin(n,p)X \sim \text{Bin}(n, p)X∼Bin(n,p) counts the successes in nnn independent Bernoulli(p)(p)(p) trials, all sharing the same ppp:

P(X=k)=(nk)pk(1−p)n−k.P(X = k) = \binom{n}{k} p^{k} (1-p)^{n-k}.P(X=k)=(kn​)pk(1−p)n−k.

The story reads straight off the formula. The factor pkqn−kp^{k} q^{n-k}pkqn−k is the chance of one particular sequence with kkk successes, and (nk)\binom{n}{k}(kn​) counts how many such sequences there are.

When p=12p = \tfrac{1}{2}p=21​ the pkqn−kp^{k} q^{n-k}pkqn−k factor is the same 1/2n1/2^{n}1/2n for every kkk, so the shape is carried entirely by (nk)\binom{n}{k}(kn​). That makes Bin(n,12)\text{Bin}(n, \tfrac{1}{2})Bin(n,21​) symmetric, peaking in the middle and tapering to the edges.

That peak is the same shape as a random walk's position and a two-dice sum, and why it peaks is worth its own note: random-walk-is-binomial.

Discrete Uniform and Hypergeometric, in brief

X∼DUnif(C)X \sim \text{DUnif}(C)X∼DUnif(C) spreads probability evenly over a finite set CCC, so P(X=x)=1/∣C∣P(X = x) = 1/|C|P(X=x)=1/∣C∣ for each x∈Cx \in Cx∈C. It is the "no reason to prefer any value" baseline.

X∼HGeom(w,b,n)X \sim \text{HGeom}(w, b, n)X∼HGeom(w,b,n) is the number of white items in a sample of nnn drawn without replacement from a jar of www white and bbb black. You pull nnn items in total, a mix of both colours, and X=kX = kX=k counts how many of them are white:

P(X=k)=(wk)(bn−k)(w+bn).P(X = k) = \frac{\binom{w}{k}\binom{b}{n-k}}{\binom{w+b}{n}}.P(X=k)=(nw+b​)(kw​)(n−kb​)​.

The numerator reads straight off that story: pick which kkk of the www white items landed in the sample, (wk)\binom{w}{k}(kw​), and which n−kn-kn−k of the bbb black ones filled the rest, (bn−k)\binom{b}{n-k}(n−kb​), over all (w+bn)\binom{w+b}{n}(nw+b​) ways to draw the sample.

The one thing to hold onto is the contrast with Binomial. Binomial is sampling with replacement, so the draws are independent and ppp never moves. Hypergeometric is sampling without replacement, so each draw changes the composition of the jar and the draws are dependent. Reach for Binomial when the pool is effectively infinite, Hypergeometric when it is a fixed finite pool. Mixing them up is an easy slip: a "count the successes" problem is only Binomial if the trials are actually independent.

A clean way to picture the Hypergeometric is that every item carries two tags, its type (white or black) and its status (sampled or not). The count kkk sits in the white-and-sampled cell.

Swapping which tag you call "type" and which you call "sample" gives a distribution that reads differently but comes out equal. Why that symmetry holds is one I have parked in probability-open-questions.

The CDF: One Descriptor for Everything

The cumulative distribution function accumulates the PMF from the left:

FX(x)=P(X≤x).F_X(x) = P(X \le x).FX​(x)=P(X≤x).

Its value at xxx is the total probability at or below xxx. The CDF is the universal descriptor because it is defined for every random variable, discrete or continuous, while the PMF only makes sense for discrete ones. It always climbs from 0 to 1 and never decreases.

For a discrete variable the two hold the same information. The CDF is the running sum of the PMF, and the PMF is recovered as the size of each jump in the CDF, the jump at xxx being exactly pX(x)p_X(x)pX​(x).

Building New Random Variables

Because a random variable is a function on Ω\OmegaΩ, any function of it, g(X)g(X)g(X), is again a function on Ω\OmegaΩ, so it is another random variable. X2X^{2}X2, 2X2X2X, and ∣X∣|X|∣X∣ are all random variables in their own right.

This gives a handy technique for a variable whose distribution you do not recognize: express it as a one-to-one function of a variable you do know. A one-to-one ggg relabels the values without merging any of them, so each new value inherits the probability of the old one it came from. That is the trick behind the random walk, whose position is a one-to-one relabelling of a Binomial count, worked in random-walk-is-binomial.

Two Category Errors to Avoid

Blitzstein calls these "sympathetic magic": treating a random variable as if it were its distribution, or as if it were a plain number.

Same PMF does not mean same variable Let XXX be the indicator of heads on one fair toss, and let Y=1−XY = 1 - XY=1−X. Both are Bern(12)\text{Bern}(\tfrac{1}{2})Bern(21​), so they have the identical PMF. They are still not the same random variable: on every outcome they disagree, since YYY is 1 exactly when XXX is 0. The PMF is a summary of a variable, not the variable itself.

The second slip is doubling. To get the PMF of 2X2X2X you cannot double the PMF of XXX. The values double, the probabilities do not. P(2X=4)P(2X = 4)P(2X=4) equals P(X=2)P(X = 2)P(X=2), since the probability stays with its outcome and only the label moves. Doubling the probabilities instead would not even leave them summing to 1.
